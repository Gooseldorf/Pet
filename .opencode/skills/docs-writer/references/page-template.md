# Page Template

Use this default page structure unless the topic clearly needs a workflow format.

```md
# Title

## Purpose
## Scope
## Source Of Truth
## Current Implementation
## Conventions
## Related Files
## Related Docs
## Open Questions
```

For workflow pages, use:

```md
# Workflow Name

## Goal
## Preconditions
## Rules
## Suggested Steps
## Verification
## Related Docs
```
