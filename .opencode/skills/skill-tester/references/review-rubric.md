## Review Rubric

Score each dimension informally as strong, acceptable, or weak.

### Description

- strong: clearly states what the skill does and when it should trigger
- acceptable: understandable but missing strong trigger language
- weak: generic, ambiguous, or too broad

### Workflow

- strong: concise, actionable, and reusable
- acceptable: mostly usable but missing decision points
- weak: vague, bloated, or not actually operational

### Packaging

- strong: clean split between main file and supporting materials
- acceptable: works, but some content is misplaced
- weak: everything dumped into one file or many unused files added

### Reuse

- strong: generalizes well beyond the original task
- acceptable: reusable with minor cleanup
- weak: overfit to a single example or one conversation
