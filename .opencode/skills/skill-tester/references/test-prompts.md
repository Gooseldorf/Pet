## Trigger Test Prompt Ideas

Use prompts like these to sanity-check a skill.

### Direct trigger

- "Create a reusable OpenCode skill for triaging bug reports."
- "Improve this `SKILL.md` so it triggers more reliably."

### Indirect trigger

- "We keep repeating the same release checklist. Turn it into something reusable for the agent."
- "Can you package this workflow so the assistant knows how to do it next time?"

### Near miss

- "Explain how skills work in OpenCode." 
- "Find a bug in this Unity script." 

The near miss should not necessarily trigger a skill-authoring skill unless the user also asks to create, adapt, or validate a skill.
