# Pet

Pet is my personal side project that I work on in my free time.

I use this repository as a playground for trying different ideas, mechanics, technical approaches, and Unity architecture experiments.

Right now, I am especially inspired by SpiderHeck, and I want to explore making something similar, but in 3D.

## Tech Stack

- Unity 6000.5.3f1
- URP
- VContainer
- UniTask
- R3
- Unity Input System
- Cinemachine
